## 输入、交付和验收

输入为 JSON 材料；读取并验证非空字符串 `owner_user_id/title/text`，输出诊断信息。占位 owner 仅用于理解数据归属，不提供真实认证。

助手已经运行正常、缺标题、空标题、非法 JSON、不可信正文、缺地区和缺文件案例；详见 [实际运行记录](../../project_steps/00_01_material_input/RUN_RESULTS.md)。当前缺 region 案例仍退出 0，这证明练习未实现。

用户下一步：自己加入 `region` 必须是非空字符串的规则，运行正常、缺 region、非字符串、纯空白地区案例，提交命令/输出及解释。预期正常退出 0，非法地区退出 2 且定位字段；这些新增验收尚未执行。

功能验收：诊断行为及错误定位符合上述规则。能力验收：用户能解释字典取值、类型检查、短路逻辑及异常如何到达入口，并能独立定位至少一次失败。
