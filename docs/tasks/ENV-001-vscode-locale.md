## 实际诊断与修复

VS Code CLI 版本 1.141.0，官方简体中文包 `ms-ceintl.vscode-language-pack-zh-hans@1.131.2026090407` 已安装，语言包翻译路径存在。

发现用户 `.vscode/argv.json` 在 locale 字段后提前闭合对象，后面 crash reporter 字段落在对象外。窗口警告也明确提示 argv.json 包含错误。这是格式问题，不能用在项目 settings.json 添加语言项来修复。

先将原文件备份为同目录 `argv.json.backup-20261009-162233`，再修正提前闭合的括号，保留原注释和其他启动参数。剔除整行注释后通过 JSON 解析，验证 locale=zh-cn；没有将个人配置或备份提交仓库。

官方 CLI 安装检查返回语言包已安装，没有假报更新版本。接下来在现有窗口用显示语言命令选择简中并验证；窗口有未保存缓冲区，不强制终止或擅自保存用户代码。

官方依据：[显示语言](https://code.visualstudio.com/docs/configure/locales)：设置写入用户 argv.json，语言变更需要重启；简中 locale 为 zh-cn。
