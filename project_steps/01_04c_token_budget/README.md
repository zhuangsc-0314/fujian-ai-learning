## 为什么现在学

token用量不是金额。以后平台需要控制调用规模，先练习价格单位、未知信息和预算前提；这只是预算规划，没有实现强制额度保护或核验账单。

新概念三个：

1. **每百万token单价**：如USD 0.15/百万输入token，不是每个token0.15美元，计算时要除以1,000,000。
2. **情景估算**：缓存命中/未命中单价不同；缺缓存明细时给全命中到全未命中的理论区间。估算不是实际扣费，账户币种/请求时段/账单均未核对。
3. **Decimal**：Python标准库的十进制数。用`Decimal("0.15")`从字符串创建，避免先经浮点近似；无需安装包。不要提前将微小费用舍入到两位小数，否则会显示0.00。

## 输入 → 处理 → 输出

输入：历史用量147/59、[官方价格快照](PRICE_SNAPSHOT.md)、明确选择的off-peak/peak情景。处理：按百万单位换算输入与输出费用，缓存明细未知时取两种边界。输出：美元估算区间；不是本次API响应/真实账单。

固定价目下的公式：

```text
费用 = (缓存命中输入 × 命中单价
      + 缓存未命中输入 × 未命中单价
      + 输出token × 输出单价) / 1,000,000
```

本课没有两类输入明细，所以分别假设全部命中、全部未命中；同一份输入只归入其中一类，不重复计算。空闲/全未命中最小例：`(147 × 0.15 + 59 × 0.6) / 1,000,000 = 0.00005745 USD`。
