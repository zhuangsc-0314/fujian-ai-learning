## 本课交付与原因

预期交付：本机HTTP请求 → 输入模型/本机上下文 → 业务服务 → 候选/保存/查询响应。

为什么现在学：让页面调用已学业务服务，而不是把LangChain调用复制到每条路由。

前置：2.9-B；FastAPI/ASGI服务依赖开课时添加锁定，当前骨架不启动端口。

新概念（最多3项）：请求/响应模型；路由；依赖提供。
